warning Canonical của trang chủ là // — giá trị rỗngThe homepage canonical is // — an empty value

Lỗi này trùng khớp với mục "Duplicate without user-selected canonical" đang có 3 trang trong GSC, và cũng trùng với mục <loc>//</loc> hỏng trong sitemap — nhiều khả năng cùng một lỗi sinh URL trong hệ thống. Per earlier scans the homepage declares <link rel="canonical" href="//"> (re-read on the 14 Oct scan: the value is still //). That is an empty protocol-relative URL pointing at no page at all; it should read https://www.feeldx.com/. This lines up with the "Duplicate without user-selected canonical" bucket currently holding 3 pages in GSC, and with the malformed <loc>//</loc> entry in the sitemap — most likely the same URL-generation bug in the CMS.
Sửa canonical trang chủ thành URL tuyệt đối https://www.feeldx.com/, rồi kiểm tra cùng đoạn code đang sinh mục // trong sitemap. Set the homepage canonical to the absolute https://www.feeldx.com/, then check the same code path that emits the // sitemap entry.
info Title dài 65–89 ký tự, bị cắt trong kết quả tìm kiếmTitles run 65–89 characters and get truncated in search results
